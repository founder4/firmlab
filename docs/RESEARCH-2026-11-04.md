# Research evidence — 2026-11-04

## Official RP2350 universal PICOBIN samples

FirmLab was checked against Raspberry Pi's official `pico-sdk-prebuilts` v2.3.1-0 release rather than only
synthetic fixtures. The artifacts remained under `/tmp`; this did not add firmware to the repository or mutate the
corpus/database.

Sources:

- <https://github.com/raspberrypi/pico-sdk-prebuilts/releases/tag/v2.3.1-0>
- <https://github.com/raspberrypi/pico-examples/blob/master/universal/README.md>
- `picotool-2.3.1-x86_64-lin.tar.gz` from
  <https://github.com/raspberrypi/pico-sdk-tools/releases/tag/v2.3.1-0>, verified against the release digest
  `sha256:878a1a1e7d8336b8be60300c7218f366d9790c0d3a211b181d6d172e80b1248e`.

The universal UF2 payload for family `0xe48bff56` was reconstructed in address order into a raw image. Hashes and
observations:

Both call graphs stopped honestly when radare2 could not decode a subsequent resolved target; neither result is
reported as whole-image coverage. The real `nuke_universal` sample also exposed signed negative relative storage
offsets in `LOAD_MAP`. Core now sign-extends them before the API maps storage bytes, while absolute storage
addresses remain unsigned.

## FreeRTOS runtime matrix revalidation

`apps/api/scripts/rtos-freertos-layout-matrix.sh` rebuilt the local FreeRTOS V11.1.0 STM32F4 fixture and passed all
8 supported runtime layouts: 16/32-bit `TickType_t`, mini list item enabled/disabled and list-integrity words
enabled/disabled. Every case ran in the `firmlab-firmware:latest` container with `--network none`, booted under
Renode, captured the 256 KiB SRAM region and corroborated the exact known occupants:

- ready: `IDLE` priority 0 and `SpinA`/`SpinB` priority 1;
- delayed: `Sleeper` priority 2;
- suspended: `Parked` priority 3;
- `pxCurrentTCB`: one of the two priority-1 spinners;
- `uxTopReadyPriority`: value 1, agreeing with the complete ready-list array;
- integrity-enabled layouts: all 37 or 46 reached `0x5a` markers matched, depending on list layout.

The result deliberately remained `needs_runtime_reproduction` and aggregate coverage remained `partial` because
`xTasksWaitingTermination` was unresolved. Renode refused the platform's remote SVD URL while offline and completed
without it; the test did not claim to measure behavior the SVD might have changed. A 64-bit runtime fixture and
queue/event-wait lists remain the next RTOS evidence gaps.
